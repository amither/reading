# 阅读小测设计文档（DeepSeek 语音识别 + 选择题）

日期：2026-11-23
基于：`2026-11-23-reading-checkin-design.md`

## 1. 目标

孩子朗读时，边录边把音频分段送去 DeepSeek 做语音识别。提交打卡后，用识别出的文字让大模型出最多 3 道选择题，孩子点选作答，当场看到对错和讲解。全程在浏览器里直接调用 DeepSeek，不增加后端。

## 2. 已确认的决策

| 主题 | 决策 |
|---|---|
| 识别 | DeepSeek `POST /v1/tools/asr`，录音时每约 60 秒切一段并发送，不等录完 |
| 出题 | DeepSeek `POST /chat/completions`，模型 `deepseek-flash`，关闭思考，JSON 输出 |
| 题型 | 只出单项选择题，每题 3 个选项，最多 3 题 |
| 作答 | 孩子点选，立即显示对错和一句讲解；结果存入打卡记录，不影响星星 |
| 密钥 | 设置里填写，只存在本机，**不进入备份文件**；留空则整个功能关闭 |
| 失败 | 任何失败只是没有题目，不影响打卡 |

## 3. 接口约束（来自 DeepSeek 文档，已实测 CORS）

- ASR：`multipart/form-data`，字段 `file`；只收 16-bit PCM WAV 或 Ogg Opus；单次最长 120 秒、8 MiB；不支持流式；语言自动识别；返回 `{request_id, text, duration_ms}`。
- 对话：`thinking: {type: "disabled"}`；`response_format: {type: "json_object"}`，提示词里必须出现 json 并给出格式；内容无法解析时接口会返回只含空格的内容，需要重试。
- 两个接口的 CORS 预检均允许 `https://amither.github.io`，浏览器可直接调用。

## 4. 音频管线

- iPad 上 `MediaRecorder` 只出 mp4/aac，DeepSeek 不收，且分片无法单独解码。因此在录音的同时，用 `AudioWorklet` 从同一路麦克风取原始 PCM，`MediaRecorder` 仍负责保存回放用的录音。
- PCM 降采样到 16kHz 单声道（盒式平均，跨块连续），攒到约 60 秒切一段。切点在第 50 到 60 秒之间选能量最小的 200ms 窗口，避免切断字词。
- 每段编码成 WAV，按顺序依次发送识别，每段失败重试最多 3 次，仍失败则跳过该段。
- 暂停时不累积采样；重录时丢弃已有内容。
- 读完时只需等最后一段（至多 60 秒）识别完，再调用一次对话接口出题。

## 5. 出题与作答

- 识别文字太短（中文不足 20 字或英文不足 20 词）时不出题。
- 提示词要求：一年级能看懂的短句；考察内容理解和简单思考；忽略识别错误；内容少或乱时可少出甚至返回空。
- 解析时校验：每题恰好 3 个互不相同的非空选项，`answer` 为 0 到 2 的整数；不合格的题丢弃；最多取 3 题。
- 解析后在代码里随机打乱选项顺序，避免模型总把正确答案放在同一个位置。
- 内容为空白时重试一次。

## 6. 流程与界面

- 点「提交打卡」：先保存打卡，再在后台收尾识别和出题，同时进入答题页 `/task/:id/quiz/:date`。
- 答题页：出题中显示「正在出题…」和「先不答题」按钮；有题时一次一题，三个大按钮；答完显示「答对 X/3」。已答过的题不能改。
- 打卡记录页：显示「阅读小测：答对 X/3」，未答完时有「去答题」入口。
- 没填密钥或没有题目：提交后直接回到任务详情页，不出现任何提示。
- 出题状态只在内存里（`running`），页面刷新后若题目还没写入就视为没有题目。

## 7. 数据

`Checkin` 增加两个可选字段，旧数据不受影响，备份格式版本不变：

- `transcript?: string`：识别出的全文。
- `quiz?: { questions: {q, options[3], answer, explain}[]; picks: (number|null)[] }`。

密钥单独存在 IndexedDB 的 `kv` 里，不属于 `Settings`，所以备份（只打包 `Settings`、打卡和录音）不会带上它；清空记录也不会删除它。

## 8. 测试

- 单元测试（Vitest）：WAV 编码、降采样（含分块一致性）、静音切点、分段器、题目解析与校验、选项打乱、识别文字门槛、DeepSeek 调用（假 `fetch`）、实时识别的顺序和失败跳过、出题落库与答题、备份不含密钥。
- iPad 真机验证：`AudioWorklet` 取音、iOS 采样率、手势内恢复 `AudioContext`、锁屏中断、长录音多段识别。

## 9. 不在范围内

离线补识别、口头回答的识别和判分、家长评分、题目难度调节、除选择题以外的题型。
